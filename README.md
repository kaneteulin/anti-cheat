# AntiCheat - Paper 26.3

핵 의심 행동을 감지해 **관리자에게 알리는** 마인크래프트 서버 플러그인입니다.
처벌(킥, 밴, 위치 되돌리기)은 하지 않습니다.

## 설치

Paper 26.3 서버의 `plugins` 폴더에 Releases 의 `AntiCheat.jar` 를 넣고 서버를 켭니다.
Paper 26.3 전용입니다 (서버 내부 코드를 일부 사용).

### 서버째로 실행 (server.ps1)

1. [Java 25 이상](https://adoptium.net/) 설치
2. 이 저장소의 `server.ps1`, `server.bat` 을 빈 폴더에 받기
3. `server.bat` 더블클릭

Paper 서버와 AntiCheat(Releases 의 최신 버전)이 자동으로 설치되고 서버가 시작됩니다.
`server.ps1` 옆에 `anti-cheat` 소스 폴더가 있으면 Releases 대신 직접 빌드합니다 (JDK 25 이상 필요).

## 작동 방식

- 각 검사는 의심 행동을 발견할 때마다 **위반 점수(VL)** 를 올립니다.
- 점수는 시간이 지나면 조금씩 줄어들고, 검사마다 정한 기준(threshold) 이상이 되면 알립니다.
- 로그는 날짜별로 `plugins/AntiCheat/logs/violations-날짜.log` 에 남습니다. 자정이 되면 그날의 빈 로그 파일이 바로 만들어집니다.
- 로그는 **항상 암호화**되어 서버 관리자나 플레이어가 열어도 읽을 수 없습니다 (설정으로 끌 수 없음).
  플러그인에는 잠그는 키(공개 키 `log-public.key`)만 들어 있고, 여는 키(비밀 키)는 저장소 밖에 따로 보관합니다.
  해독: `java anti-cheat/tools/DecryptLog.java <로그 파일 또는 logs 폴더> <비밀 키 파일> [출력 파일]`
- **기본 설정은 오탐 테스트용**입니다: 채팅·콘솔 알림 없이, 기준 미만까지 모든 의심 행동을 날짜별 로그 파일에만 기록합니다.
  `config.yml` 의 `alerts.chat`, `alerts.console` 을 `true` 로, `alerts.log-all` 을 `false` 로 바꾸면 기준 이상일 때만 OP 채팅·콘솔·로그에 알립니다.
- 이동 검사는 서버 시간이 아니라 **플레이어가 보낸 이동 정보 단위**로 세기 때문에, 컴퓨터가 잠깐 멈추거나 렉이 걸려도 잘못 잡히지 않도록 했습니다.

## 검사 목록

### 오탐 위험 중간
| 검사 | 설정 이름 | 내용 |
|---|---|---|
| 공격 거리 | `reach` | 기본 거리 + 0.5칸 + 핑 보정보다 멀리서 공격 |
| 비행 | `fly` | 점프 꼭대기를 지났는데도 떨어지지 않고 공중에 머묾 |
| 점프 높이 / 벽타기 | `jump` | 땅을 떠난 뒤 정상 점프(점프 강화 포함)보다 높이 올라감 |
| 낙하 피해 무시 | `nofall` | 떨어지는 중인데 땅에 닿았다고 보냄 |
| 빠른 채굴 | `fastbreak` | 정상 채굴 시간의 60% 보다 빨리 캠 |
| 대량 채굴 | `nuker` | 캐는 데 시간이 걸리는 블록을 1초에 6개 넘게 캠, 캐기 시작 없이 부숨 |
| 오토클릭 | `autoclicker` | 초당 클릭 25회 초과가 2초 연속 (블록 캐는 중 제외) |

### 오탐 위험 높음 (정상 플레이에서도 걸릴 수 있음, 처벌에 쓰기 전에 충분히 테스트 필요)
| 검사 | 설정 이름 | 내용 |
|---|---|---|
| 타이머 | `timer` | 클라이언트 틱이 정상(50ms)보다 누적 0.4초 이상 빠름. 네트워크가 멈췄다가 몰려 온 패킷은 최대 10초까지 인정 |
| 이동 속도 | `speed` | 이동 속도 능력치(달리기, 신속, 영혼 가속 포함)로 계산한 최대 속도를 계속 넘음 (얼음 위 2.6배) |
| 넉백 무시 | `velocity` | 넉백을 받고 (핑 + 0.4초) 뒤에도 넉백 방향으로 거의 밀려나지 않음 (뒤가 벽이면 제외) |
| 킬오라 | `killaura` | 보는 방향과 75° 넘게 벗어난 대상 공격, 0.05초 안에 서로 다른 대상 공격 |
| 겉날개 비행 | `elytra` | 폭죽 없이 4초 이상 상승, 속도 4.2칸/틱 초과, 활공 중 공중 정지 |
| 블록 통과 | `phase` | 몸이 단단한 블록 안으로 들어가거나 한 번에 벽을 뚫고 지나감 |
| 자동 다리 놓기 | `scaffold` | 보지 않는 면(100° 초과)에 블록 설치, 발밑에 1초에 12개 넘게 설치 |

빠른 먹기는 지금 버전에서 서버가 먹는 시간을 직접 계산하므로 핵으로도 불가능해 검사하지 않습니다.

다음 상황에서는 이동 검사를 하지 않습니다: 크리에이티브/관전자, 비행 허용, 겉날개, 급류, 공중 부양/느린 낙하 효과,
탈것, 물/용암/사다리/거미줄/가루눈/거품 기둥/꿀/슬라임 근처, 슬라임·침대에서 튀어 오를 때,
접속·리스폰·텔레포트·넉백·피해·폭발(바람 돌격 포함)·피스톤 직후 잠시.

## 자동 백업

4시간마다 서버를 `backups/backup-날짜_시각.zip` 으로 백업합니다 (월드 전체, 서버 설정 파일, `plugins/AntiCheat`).

- 월드를 저장한 뒤 압축하는 동안 자동 저장을 잠시 끄고, 압축은 별도 스레드에서 해서 서버가 멈추지 않습니다.
- 백업은 지우지 않고 모두 보관합니다. 디스크가 부족해지면 `backups` 폴더의 오래된 파일을 직접 지우거나, `backup.keep` 에 남길 개수를 정하세요.
- 간격, 남길 개수, 폴더는 `config.yml` 의 `backup` 에서 바꿀 수 있습니다. 바로 백업하려면 콘솔에서 `ac backup`.
- 복구: 서버를 끈 뒤 zip 안의 파일로 서버 폴더의 같은 파일을 바꿉니다.

## 정보 이용형 치트 대응

X-ray, ESP 처럼 화면에 보이는 정보를 이용하는 치트는 감지할 수 없으므로, **서버가 정보를 덜 보내는 방식**으로 막습니다.
`config.yml` 의 `info-protection` 에서 각각 끌 수 있습니다.

| 치트 | 설정 이름 | 대응 |
|---|---|---|
| X-ray, 상자 ESP | `anti-xray` | 땅속(오버월드 높이 64 아래, 네더 128 아래)의 광석과 상자·통·엔더 상자·생성기를 가짜 광석 사이에 숨김 |
| 플레이어/몹/아이템 ESP, 트레이서, 이름표 투시 | `entity-hiding` | 꽉 찬 불투명 블록에 완전히 가려진 대상의 정보를 보내지 않음 (반 블록·계단·울타리·문 등 너머는 보임, 핑을 고려해 넉넉하게 판단). 6칸 안, 발광 효과, 한 번 보인 뒤 1초 동안은 항상 보임. Tab 목록에서는 사라지지 않음 |
| 체력 표시 | `health` | 다른 플레이어의 체력을 20 으로, 흡수 체력을 0 으로 보냄 |
| 장비 엿보기 | `item-obfuscation` | Paper 아이템 정보 숨기기를 켜서 다른 플레이어 장비의 인챈트·내구도 등을 숨김 |
| 시드 크래킹 | `seeds` | 구조물 생성 시드를 무작위로 바꾸고, 광석·나무 등 생성 시드도 월드 시드와 다르게 함 (요새는 제외) |
| 소리 추적 | `sounds` | 위더 소환, 엔드 포털, 드래곤 죽음 소리가 월드 전체 대신 64칸 안에서만 들림 |

- 처음 설치한 뒤에는 **서버를 한 번 다시 시작**해야 모두 적용됩니다 (콘솔에 안내가 나옵니다).
- 시드 변경은 **새로 생성되는 지형부터** 적용됩니다. 이미 있는 월드에서는 경계에서 구조물이 잘려 보일 수 있습니다.
- 숨긴 플레이어가 낸 소리와 블록 캐는 모습은 서버가 원래 보내지 않으므로, 플레이어 숨기기가 소리 추적도 함께 줄입니다.
- 서버에서 막을 수 없는 것: 프리캠, 풀브라이트, 미니맵의 지형, 좌표 표시 (플레이어 컴퓨터가 처리하는 정보).
  위 대응으로 이 치트들이 볼 수 있는 정보가 줄어듭니다.

## 설정

`plugins/AntiCheat/config.yml` 에서 검사마다 켜고 끄거나(`enabled`) 알림 기준(`threshold`)을 바꿀 수 있습니다.
바꾼 뒤 콘솔에서 `ac reload`.

## 명령어 (`/anticheat`, `/ac`)

| 명령어 | 내용 |
|---|---|
| `/ac alerts` | 내 알림 켜기/끄기 |
| `/ac vl <닉네임>` | 위반 점수 보기 |
| `/ac reload` | 설정 다시 읽기 |
| `/ac backup` | 지금 바로 백업 |

## 권한

| 권한 | 기본 | 내용 |
|---|---|---|
| `anticheat.alerts` | OP | 알림 받기 |
| `anticheat.admin` | OP | 명령어 사용 |
| `anticheat.bypass` | 없음 | 모든 검사에서 제외 |
